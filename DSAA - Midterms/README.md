# School Subjects

## Description

This Java program displays the subjects for Grade 1 to Grade 5.

It uses arrays, a two-dimensional array, and nested loops to organize and display each grade level and its subjects.

## Subjects

- Grade 1: Mother Tongue, Filipino
- Grade 2: ESP, English
- Grade 3: Araling Panlipunan, MAPEH
- Grade 4: Science, EPP
- Grade 5: Math, TLE

## Concepts Used

- Arrays
- 2D Arrays
- For Loops
- Nested Loops
- Console Output
