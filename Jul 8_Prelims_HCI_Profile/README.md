# Personal Profile Display

## Description

A simple Java assignment that displays a personal profile using a separate method and predefined information.

## Features

- Displays personal information in an organized format
- Uses a method with multiple parameters
- Uses a conditional statement for the pet-person display
- Uses variables to store profile information
- Does not require user input

## Information Displayed

- Pet Person
- Name
- Nickname
- Birthday
- Address
- Favorite Song
- Motivation
- Support
- Personal Quote

## Concepts Used

- Methods
- Parameters
- Variables
- Conditional Statements
- `System.out.println()`
- String manipulation

## How to Run

Open the Java file in a Java compiler such as **OnlineGDB** or **Visual Studio Code**.

For OnlineGDB:

1. Select **Java** as the language.
2. Paste the Java code into the editor.
3. Click **Run**.
