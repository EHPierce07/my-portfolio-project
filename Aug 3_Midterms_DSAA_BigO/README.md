# Big O Examples

## Description

This Java program demonstrates different Big O time complexity classes through simple examples and algorithms.

The program covers eight major complexity classes, ranging from constant time to factorial time.

## Complexities Covered

- O(1) - Constant
- O(log n) - Logarithmic
- O(n) - Linear
- O(n log n) - Linearithmic
- O(n²) - Quadratic
- O(n³) - Cubic
- O(2ⁿ) - Exponential
- O(n!) - Factorial

## Examples Used

### O(1)
Accesses the first element of an array.

### O(log n)
Uses Binary Search to find an element in a sorted array.

### O(n)
Finds the largest value by checking each element once.

### O(n log n)
Uses Merge Sort to sort an array.

### O(n²)
Generates pairs using two nested loops.

### O(n³)
Generates combinations using three nested loops.

### O(2ⁿ)
Uses a recursive Fibonacci function.

### O(n!)
Generates all possible permutations of a string.
