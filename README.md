# Student Grade Analyzer

## Description

A Java assignment that demonstrates basic programming concepts using arrays, loops, conditional statements, and methods.

## Features

- Stores student grades using an array
- Displays all grades using a loop
- Finds the highest grade
- Determines whether each grade is passed or failed
- Uses separate methods to keep the program organized

## Concepts Used

- Arrays
- For-each loops
- If-else statements
- Methods
- Parameters and return values

## How to Run

Compile the program:

```bash
javac Main.java
```

Run the program:

```bash
java Main
```
