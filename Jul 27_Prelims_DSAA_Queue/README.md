# Data Structures Practice

## Description

This Java program demonstrates different basic data structure and array operations.

The program contains separate methods that demonstrate reversing an array, using a Stack, using a Priority Queue, and identifying even numbers from an array.

## Features

### Reversed Array
Displays the elements of an integer array starting from the last element to the first.

### Stack
Demonstrates the basic operations of a Stack using:
- `push()` to add elements
- `pop()` to remove the top element

### Queue
Demonstrates a Priority Queue using:
- `add()` to insert elements
- `poll()` to remove an element

### Even Numbers
Checks an integer array and displays the numbers that are even using an `if` statement and the modulo operator.

## Concepts Used

- Arrays
- For Loops
- If Statements
- Methods
- Stack
- Priority Queue
- `push()`
- `pop()`
- `add()`
- `poll()`
- Modulo Operator

## Program Structure

The program is divided into several methods:

- `ReversedArray()` - displays an array in reverse order
- `Stack()` - demonstrates Stack operations
- `QueueFunct()` - demonstrates Priority Queue operations
- `EvenNums()` - finds and displays even numbers
- `main()` - runs all the methods

## File

## Purpose

This project is a practice exercise for understanding basic data structures, arrays, loops, and methods in Java.
