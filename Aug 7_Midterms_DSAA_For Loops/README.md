# School Subjects

## Description

This Java program displays the subjects assigned to Grade 1 to Grade 5.

It uses arrays, a two-dimensional array, and nested loops to organize and display each grade level and its corresponding subjects.

## Grade Levels and Subjects

- Grade 1: Mother Tongue, Filipino
- Grade 2: ESP, English
- Grade 3: Araling Panlipunan, MAPEH
- Grade 4: Science, EPP
- Grade 5: Math, TLE

## Concepts Used

- Arrays
- Two-Dimensional Arrays
- For Loops
- Nested For Loops
- String Data
- Console Output

## Program Structure

The program stores the grade levels in an array and the corresponding subjects in a two-dimensional array.

A nested `for` loop is used to display the subjects for each grade level.

## File

`SchoolSubjects.java`

## Purpose

This project demonstrates the use of arrays and loops in Java while organizing school subjects according to their corresponding grade levels.
